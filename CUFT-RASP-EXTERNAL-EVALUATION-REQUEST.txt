THE AXIOM
===============================================================================

Consider the gated cubic recursion:

    f(x) = Gamma * tanh^3(x) - lambda * x

where Gamma > 0 is the coherence strength and lambda >= 0 is a damping
parameter. This is a one-dimensional iterated map x_{t+1} = f(x_t).

For Gamma > 1 and small lambda, this map has three fixed points:
    x = 0        (stable, trivial vacuum)
    x = x_u      (unstable, basin boundary / confinement threshold)
    x = x_s      (stable, confined state)

The fixed point equation is: Gamma * tanh^3(x) = (1 + lambda) * x

Physical inputs:

    n = 3               (QCD quark count)

STEP 1 — GAIN-COHERENCE (continuous selection)

    At lambda = 0, ask: for what Gamma does the derivative at x_u,
    raised to the n-th power, equal Gamma itself?

    Equation: [f'(x_u)]^n = Gamma  at lambda = 0

    where f'(x) = 3*Gamma*tanh^2(x)*sech^2(x)

    This is ONE equation in ONE unknown (Gamma). Solving numerically:

        Gamma_classical = 24.8377
        sqrt(Gamma_classical) = 4.9837

    Physical interpretation: the recursion's amplification gain at the
    unstable threshold, compounded n times (once per quark), must
    reproduce the coherence strength. This is a self-consistency
    condition on the dynamics.


STEP 2 — INTEGER QUANTIZATION (Bohr step)

    The key postulate: sqrt(Gamma) must be an integer p.

    Why? The coupling between quarks and the confining field is
    kappa = 1/sqrt(Gamma) = 1/p. For n quarks to phase-lock into a
    coherent bound state, this coupling must be commensurate —
    irrational kappa leads to decoherence of the n-fold oscillation.

    From sqrt(Gamma_classical) = 4.9837:
        Nearest integer: p = 5 (distance 0.0163)
        Next nearest: p = 4 (distance 0.9837) or p = 6 (distance 1.0163)

    The quantization is UNAMBIGUOUS. p = 5 with no competition.

    Therefore:
        p = 5
        Gamma = p^2 = 25
        kappa = 1/p = 1/5 = 0.2

    Quantization error: |24.8377 - 25|/25 = 0.65%

    This is analogous to Bohr quantization: continuous classical mechanics
    selects a continuous parameter, then an integer constraint snaps it

SUPPORTING THEOREMS AND IDENTITIES
===============================================================================

THEOREM: COHERENT ENERGY
    Why X^2/2 and not X^2/(2n)?

    A single quark oscillating with amplitude A has energy A^2/2.
    Three quarks independently: 3 * (X/3)^2/2 = X^2/6.
    But if they phase-lock (coherent oscillation), the collective
    amplitude is X and the energy is X^2/2 — a factor of n = 3 enhancement.

    This is the same physics as superradiance (Dicke 1954): n coherent
    emitters produce n^2 intensity, not n times single-emitter intensity.
    The leading 98% of the proton mass (1800 out of 1836) comes from
    this coherent enhancement.


THEOREM: GAIN-QUARK IDENTITY
    f'(x_u) = 2.933  (at physical parameters)

    To leading order in 1/Gamma:
        f'(x_u) = n - n/Gamma + O(1/Gamma^2) = 3 - 0.12 + ... = 2.88

    The recursion gain at the unstable fixed point IS the quark count
    (to 2.2% accuracy). This connects the map dynamics to QCD.


THEOREM: BARE UV THRESHOLD
    At lambda = 0, the unstable fixed point satisfies:
        x_u = 1/sqrt(Gamma) * [1 + 1/(2*Gamma) + O(1/Gamma^2)]

    At Gamma = 25: x_u(bare) = 0.2042 vs kappa = 1/5 = 0.2000
    Gap: 2.1% = O(1/Gamma)

    Physical meaning: kappa = 1/p equals the bare confinement activation
    threshold to leading order. The coupling IS the basin boundary.

    The O(1/Gamma) correction is absorbed by the integer quantization.


THEOREM: CORNELL POTENTIAL STRUCTURE
    The mass formula M = X^2/2 + (n/p)*X + n^2/X + lambda/n maps to the
    Cornell quark potential V(r) = sigma*r - alpha_s/r + C:

    | X^2/2          | Kinetic/coherent | 1800     |

    | n^2/X          | -alpha/r (Coulomb)| 0.15    |
    | lambda/n       | C (vacuum)       | 0.003    |

    String tension sigma = n/p = 3/5 = 0.6, Coulomb coefficient A = n^2 = 9.


NEW IDENTITY: p^3 ~ (1+lambda)/lambda
    From the fixed-point sum x_u + x_s = Gamma (exact at lambda=0):
        x_s = Gamma/(1+lambda), x_u = Gamma*lambda/(1+lambda)
        Setting x_u = 1/sqrt(Gamma): Gamma^(3/2) = (1+lambda)/lambda
        Therefore: p^3 = (1+lambda)/lambda

COMPARISON TO EXISTING WORK
===============================================================================

We searched extensively for prior work with similar approaches:

1. LATTICE QCD (BMW Collaboration, 2008):
    Computes proton mass numerically from first principles of QCD.
    Result: M_proton = 938 +/- 25 MeV (2.7% error).
    KEY DIFFERENCE: Lattice QCD requires massive computation, produces
    no closed-form formula, and uses 4+ inputs (quark masses, alpha_s, etc.)

2. KOIDE FORMULA (1981):
    (m_e + m_mu + m_tau) / (sqrt(m_e) + sqrt(m_mu) + sqrt(m_tau))^2 = 2/3
    Algebraic mass relation, 0.03% accurate, no known derivation.
    KEY DIFFERENCE: Koide has no dynamics, no recursion, and applies to
    leptons not baryons. But it's the closest precedent for algebraic
    mass relations without standard model derivation.

3. ALGEBRAIC PROTON MASS FORMULAS:
    Several exist (e.g., M ~ 6*pi^5), all backward-fitted with no dynamics.
    KEY DIFFERENCE: CUFT-RASP has dynamics (the recursion) and forward-derives
    Gamma from gain-coherence. The Diophantine is algebraic but NOT ad hoc —
    it follows from the virial relation.

4. THE PROTON-TO-ELECTRON MASS RATIO:
    Remains an unexplained constant in the Standard Model. Lattice QCD

WHAT WE THINK ARE THE WEAKNESSES
===============================================================================

1. WHY TANH^3? The axiom f(x) = Gamma*tanh^3(x) - lambda*x is asserted,
   not derived from a deeper theory. Why cubic? Why tanh? A skeptic could
   argue this is chosen to give the right answer.

   Our defense: tanh^3 is the simplest saturating odd-power nonlinearity.
   tanh^1 has no unstable fixed point. tanh^5 works but gives different
   (wrong) numbers. The cubic is the minimal model with the right
   fixed-point structure.

2. THE 2% GAP: kappa = 1/p = 0.200 vs x_u(bare) = 0.204 (2.1% off).
   The integer quantization absorbs this, but a rigorous derivation of
   WHY kappa equals the integer-quantized bare threshold would be stronger.

3. LAMBDA PROVENANCE: lambda = 0.008097 is input, not derived. The
   identity p^3 ~ (1+lambda)/lambda is 0.4% accurate but not exact.
   If lambda could be derived from the recursion, the theory would have
   only ONE input (n=3).

4. MASS FORMULA DERIVATION: The formula M = X^2/2 + (n/p)X + n^2/X + lambda/n
   is motivated by analogy with the Cornell potential and coherent energy
   arguments, but it is not rigorously derived from the recursion dynamics
   as a time-averaged energy. A Lagrangian derivation would be stronger.

5. BARYON SPECTRUM: The 8 baryon predictions use a prescription for how
   strange quarks modify the parameters. This prescription works but
   adds model-dependent assumptions beyond the core derivation.

NUMERICAL VERIFICATION

All claims can be verified with this Python code:

```python
import numpy as np
from scipy.optimize import brentq

# Parameters
n, p, GAMMA, LAMBDA = 3, 5, 25, 0.008097

# Fixed points
x_u = brentq(lambda x: GAMMA*np.tanh(x)**3 - (1+LAMBDA)*x, 0.01, 1.0)
x_s = brentq(lambda x: GAMMA*np.tanh(x)**3 - (1+LAMBDA)*x, 2, 30)

# Gain at x_u
t = np.tanh(x_u)
fp = 3*GAMMA*t**2*(1-t**2) - LAMBDA
print(f"x_u = {x_u:.10f}")       # 0.2050317417
print(f"x_s = {x_s:.10f}")       # 24.7991748...
print(f"f'(x_u) = {fp:.6f}")     # 2.933071
print(f"f'(x_u)^3 = {fp**3:.4f}")  # 25.233

# Gamma_classical from gain-coherence at lambda=0
def gc(G):
    xu = brentq(lambda x: G*np.tanh(x)**3 - x, 0.001, 0.9)
    t = np.tanh(xu)
    return (3*G*t**2*(1-t**2))**3 - G
G_cl = brentq(gc, 20, 30)
print(f"Gamma_classical = {G_cl:.6f}")  # 24.837669

# Mass
X = n * p * (p - 1)  # = 60
M = X**2/2 + X*(n/p) + n**2/X + LAMBDA/n
M_exp = 1836.15267343
print(f"X = {X}")                         # 60
print(f"M = {M:.6f}")                     # 1836.152699
print(f"M_exp = {M_exp}")                 # 1836.15267343
print(f"Error = {abs(M-M_exp)/M_exp*1e9:.0f} ppb")  # 14 ppb

# Diophantine check
print(f"(n-2)(p-1) = {(n-2)*(p-1)}")     # 4
```
