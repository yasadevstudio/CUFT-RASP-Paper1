# CUFT-RASP Paper 1

**Four Fundamental Constants of Nature from a Gated Cubic Recursion with Zero Free Parameters**

By Eliseu Spiller de Barros Lima

## Repository Purpose

This repository contains the arXiv LaTeX source, compiled PDF, and all computational verification scripts for Paper 1 of the CUFT-RASP series. Nothing else.

## Replication

Every numerical claim can be verified by running the corresponding Python script. Scripts require only standard Python 3 with numpy/scipy.
